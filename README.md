# OWASP ZAP Security Assessment

## Project Title
Web Application Security Testing using OWASP ZAP on OWASP Juice Shop

## Student Details
- **Name:** Prince Arora
- **Course:** BCA (Cyber Security)

## Project Overview
This project demonstrates web application security testing using OWASP ZAP on the OWASP Juice Shop application. The assessment identifies common web vulnerabilities and explains the associated security risks.

## Tools Used
- OWASP ZAP
- Docker
- OWASP Juice Shop

## Vulnerabilities Identified
- Missing Content Security Policy (CSP)
- Missing Security Headers
- Cross-Domain Misconfiguration
- Information Disclosure

## Project Files
- `README.md`
- `SCREENSHOTS/`
- Project Report (.docx)

## Conclusion
This project demonstrates how OWASP ZAP can be used to identify web application vulnerabilities and improve application security.
